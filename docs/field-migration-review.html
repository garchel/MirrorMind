Campos: o que muda, como fica e de onde vem

O app tem campos crus medida por node scripts/scan-fields.mjs. Esta página mostra a migração de cada grupo para <Field>, com medição no navegador antes/depois, seguindo docs/design-system-maturation.md.

Os números, medidos pelo scanner

O inventário de 2026-11-09, medido por scripts/scan-fields.mjs (exclusões: teste, Field.tsx, Button.tsx):

111 campos crus no inventário inicial — 96 <input>, 10 <textarea>, 5 <select>, em 25 arquivos. (O scanner ignora comentários; a primeira versão dele contava 3 comentários como campo — 114 era ruído.)
108 sem className — herdam o reset global; é o alvo da onda.
3 com classe estática (frontmatter-panel-key/value, postit-popover-input) — visual próprio completo.
34 checkbox/radio/color (19 + 11 + 4) — fora do escopo: o <Field> é campo de texto; o glifo precisa de decisão própria.
Placar da onda: família textual migrável = 77 (62 input textual + 10 textarea + 5 select). Migrados até agora: 32 (lote 1: 6 atalhos; lote 2: 18 do grafo; lote 3: 8 da página de tags). Restam crus: 79 (node scripts/scan-fields.mjs).

O veredito

<Field> renderiza a mesma tag com classes a mais (ui-field ui-field--size), então as regras de contexto que casam por tag (.shortcut-settings input, 0,1,1) continuam valendo e continuam vencendo as densidades do primitivo (0,1,0). Medir antes de migrar é o que confirma, contexto a contexto, se sobra algum vazamento — o mesmo processo da onda dos botões.

Atalhos de teclado — .shortcut-settings

SettingsPage 385–468 · 6 <input> readOnly

Contexto (workspace-chrome.css:783 · .shortcut-settings input, 0,1,1): declara min-height: 38px, mono 13px/1, text-align: center, fundo gold-150, borda tinta e raio 8 — o contexto vence o sm (36px) no min-height por especificidade. Medição antes/depois (CSS real, coluna de 160px): 38px/160px idênticos, mono 13px/13px idêntico, raio 8 idêntico, fundo e cor idênticos. O que muda: o padding UA 1px 2px → 0 12px (invisível: texto centrado em coluna de largura fixa) e uma transition nova de 120ms na borda/fundo (o foco do contexto, input:focus 0,2,1, vence o .ui-field:focus-visible 0,2,0 e continua desenhando o contorno tinta). Migrado como <Field size="sm">.

Grafo — header, popover de configurações e exportação

GraphToolbar 17 + GraphFilterSelect 1 · lote 2

Quatro contextos, medição antes/depois com o CSS real. Header (3 campos: 2 select + busca) ( graph.css:134 · (0,2,1)): 30px, 0 8px, raio 6, gold-50, 12px sans — idêntico. Correção no contexto: width: auto entrou na própria regra, porque .ui-field impõe width: 100% e o header é flex (o cru nasce auto; sem isso o layout quebra). Números do popover de configurações (12 campos, graph.css:337): 26px fixos com fonte mono — idêntico, mas aqui a correção era mais séria: o contexto declara só height: 26px, e height perde para min-height em qualquer especificidade — o min-height: 48px do .ui-field esticaria tudo para 48px. O contexto declara min-height: 26px. O select da tag principal ganhou width: auto pelo mesmo motivo do header. Select de exportação (graph.css:571 · 28px): idêntico; width: auto entrou também. Busca do filtro (GraphToolbar.css:91, campo embutido sem borda, flex: 1): idêntico — o flex-basis: 0% do contexto neutraliza o width: 100% do primitivo sem correção extra.

Página de tags — busca, nome e ritmo de revisão

TagManagementPage 544/601/645–649/653 · 8 campos · lote 3

Três contextos com o CSS real. Busca (tag-management.css:138 · 36px, sem borda, fundo transparente dentro do .tag-search): idêntico. Nome da tag (:584 · 40px dentro da moldura com 12px): idêntico, mas exigiu padding: 1px 2px explícito — o cru usava o padding UA e o primitivo injeta 0 12px, que empurraria o texto 10px. Ritmo (:727 · 38px fixos): o contexto só declara height, então ganhou min-height: 38px — senão o min-height: 48px do primitivo esticaria. Os 5 números e a data são o mesmo contexto (idênticos). Correção comum: :focus-visible { outline: 0 } nos três — o primitivo injetaria um anel que o cru não tinha (a busca já desenha o anel no wrapper via :focus-within).
